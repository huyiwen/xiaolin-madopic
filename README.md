# Madopic

> Madopic (Markdown to Picture) 精美的 Markdown 转图片工具 ✨

![madopic.png](https://pic4.zhimg.com/v2-a342a311176f76e4120b7084d9f18db3_r.jpg)

一个现代化的在线工具，可以将 Markdown 文本转换为精美的图片海报，特别适合社交媒体分享。

## 项目简介

Madopic 是一个功能丰富的 Markdown 可视化工具，集成了数学公式渲染、图表绘制、多格式导出等强大功能。无论是制作学术海报、技术文档，还是社交媒体内容，都能轻松胜任。



## 主要功能

### 基础功能
1. **Markdown 渲染**：将 Markdown 内容转化为精美图文海报
2. **自定义外观**：可调整背景、字体大小、边距和模式（自由/小红书/朋友圈）
3. **多格式导出**：支持 PNG、PDF、HTML，以及 Markdown 与图片打包导出
4. **所见即所得**：实时预览，快速导出
5. **图片支持**：本地选择、剪贴板粘贴，Base64 智能管理
6. **信息卡片**：支持好看的信息卡片

### 数学公式渲染
6. **KaTeX 集成**：支持行内公式 `$E=mc^{2}$` 和块级公式 `$$\int_a^b f(x)dx$$`
7. **公式模板库**：内置数学、物理、化学公式模板
8. **符号支持**：希腊字母、积分微分、矩阵等复杂数学符号

### 图表可视化
9. **Mermaid 图表**：流程图、序列图、甘特图、饼图等
10. **ECharts 数据图表**：柱状图、折线图、饼图等数据可视化
11. **一键插入**：丰富的图表模板，快速创建专业图表

### 用户体验
12. **代码块优化**：自动换行，支持长代码行完整显示
13. **预览缩放**：50%～150% 灵活查看
14. **键盘快捷键**：提升编辑效率
15. **智能通知**：操作反馈与错误提示
16. **完全开源**：MIT 协议，免费使用

## 使用方法

### 基础操作
1. **编写内容**：在左侧编辑器中输入 Markdown 文本
2. **实时预览**：右侧会实时显示渲染效果，包括数学公式和图表
3. **自定义外观**：点击"自定义"按钮调整：
   - 背景渐变色彩
   - 字体大小（12-32px）
   - 内容边距（20-80px）
   - 显示模式（自由/小红书3:4/朋友圈长图）

### 小红书手动分页

选择顶部的“小红书”模式，点击编辑器工具栏中“插入图片”右侧的“插入分页”按钮，即可在光标处插入分页符。也可以在需要换页的位置独占一行输入 `<!--madopic-new-page-->`：

```markdown
# 第一页

这里是第一页的内容。

<!--madopic-new-page-->

# 第二页

这里是第二页的内容。
```

实时预览会显示当前页，在放大/缩小按钮旁使用“上一页 / 下一页”切换，或点击预览区域后按键盘 `←` / `↑` 上一页、`→` / `↓` 下一页。在分页预览区域滚轮向上、向下也可翻页；触控板的连续惯性滚动只翻一页，停顿或反向滚动后可继续翻页。编辑文字、操作输入框或打开设置弹窗时，方向键保留原有功能，编辑器滚动和 Ctrl / Command 加滚轮也不受影响。页码显示当前位置和总页数，每页保持小红书的 3:4 比例；单页超出的内容仍会裁切，请在合适的位置手动分页。

小红书模式下，在「导出」菜单选择「PNG」会将全部页面按顺序保存为 `page-001.png`、`page-002.png` 等图片，并下载一个 ZIP 压缩包；选择「PDF」会将全部页面合并为一个 PDF 文档，保留可编辑的正文文字。「HTML」选项在小红书模式下禁用。导出从第一页开始，使用点击导出时的内容和样式，不受当前预览页或导出期间编辑的影响。

自由模式和朋友圈模式仍连续显示全文，支持单张 PNG、单个 PDF 和 HTML 导出。代码块中的分页符示例不会触发分页，开头、结尾或连续分页符产生的空白页会自动忽略。

### 文档库与自动保存

点击左上角「文档」打开侧边栏，可以新建文档、填写文档名称，并点击列表加载已保存的正文。名称留空时使用正文第一行作为标题。输入时自动保存，编辑器上方显示保存状态；切换文档前会等待保存完成，切换时重置撤销历史，避免撤销操作带入其他文档的内容。

正文保存在当前站点的 IndexedDB `madopic` 数据库、`documents` 表中，上传和粘贴的图片保存在同一数据库的 `images` 表中。旧版 `localStorage` 中的 `madopic_draft` 会在数据库保存成功后自动迁移，空文档也会保留。最近打开的文档 ID 记录在 `localStorage` 的 `madopic_active_document` 中。

页眉页脚、画布背景、正文底色、文字布局和导出模式是所有文档共用的设置，保存在 `localStorage` 的 `madopic_settings` 中。设置面板点击「应用」立即写入，取消或按 Escape 恢复上次应用的值；正文输入不会覆盖尚未应用的设置。浏览器数据按站点地址隔离，不会随 GitHub push 或 Vercel 部署同步到其他浏览器；可用 Markdown 压缩包备份正文和图片。

### 正文底色与画布背景

「背景设置」包含独立的正文卡片底色和外层画布背景。正文底色提供白色、黑色、淡黄色、淡绿色、淡蓝色预设和取色器，仅改变海报正文区域，深色底色自动使用浅色正文。预览、PNG、PDF 使用同一底色，编辑界面的颜色不随所选底色改变。页面固定配色，并声明不接受 Dark Reader 的自动改色，避免夜间预览与导出变色。

外层画布继续支持原有渐变预设，也可以自定义起始色、结束色和渐变方向，所有这些参数都会保存并在刷新时恢复。

### 页眉页脚

点击“背景设置”旁的“页眉页脚”，可分别设置每页左上角、右上角、左下角和右下角的文字。四个位置独立支持字体、字号、颜色、加粗和斜体，也可输入多行文字。

每个位置的「额外显示」可选择当前页码（`1`）、页码与总页数（`1 / 3`）、完整页码格式（`第 1 / 3 页`）或「当前文档名称」。文字留空时仅显示所选内容，有文字时显示为“文字 · 页码”或“文字 · 文档名称”。四个位置可独立选择，例如左上角显示文档名称、右下角显示页码。

文档名称与侧边栏一致，未自定义名称时使用正文第一行，空文档显示“未命名文档”；改名或切换文档后自动更新。页码随预览翻页、增删分页更新。PNG 和 PDF 的每一页都使用点击导出时的文档名称和对应页码，导出期间改名或切换文档不影响本次导出。文字留空且「额外显示」选择“不显示”时，隐藏该位置。原有页码设置会继续保留。

文字浮在画布上，不占用或改变正文的排版空间。弹窗编辑时可实时预览，点击“应用”保存，点击“取消”或按 Esc 恢复原设置。设置会随草稿保存在本地，并同步到全部分页的 PNG、PDF；PDF 正文仍保留可编辑文字，四角文字以图层保留其字体和样式。

### 数学公式

行内公式使用 `$...$` 或 `\(...\)`，独立公式使用 `$$...$$` 或 `\[...\]`。支持复杂上下标和 `aligned`、矩阵等多行环境，例如：

```latex
$(o_t)_a = \sum_{b=1}^{d_k}(q_t)_b(u_t)_c$

$$\begin{aligned}
1 & 1\\
2 & 2\\
\end{aligned}$$
```

公式内部的下划线、反斜杠和换行会原样交给 KaTeX；代码块、行内代码中的公式示例仍按代码显示。预览、PNG 和 PDF 使用相同的公式解析流程。

4. **插入公式**：点击工具栏 🧮 按钮插入数学公式模板
5. **物理公式**：点击 🔬 按钮获取物理公式（牛顿定律、电磁学等）
6. **化学公式**：点击 🧪 按钮插入化学反应方程式
7. **质能守恒**：点击 ⚛️ 按钮快速插入 E=mc²

流程图、序列图、甘特图、饼图、ECharts，以及质能守恒、数学、物理、化学公式按钮统一放在编辑器工具栏的「图表与公式」折叠菜单中，选择后自动收起。

### 图表绘制
8. **流程图**：点击 🔄 按钮创建 Mermaid 流程图
9. **序列图**：点击 ⏭️ 按钮绘制时序图
10. **甘特图**：点击 📅 按钮制作项目进度图
11. **数据图表**：点击 📊 按钮创建 ECharts 数据可视化

### 导出保存

在右上角「导出」下拉菜单选择「Markdown」，会将编辑器中的完整内容保存为 `document.md`，引用的图片放入 `images/` 目录，一起下载为 ZIP 压缩包。解压后，Markdown 中的图片通过相对路径引用，可以放到其他 Markdown 编辑器中使用。自由、小红书和朋友圈模式均支持；小红书导出包含全部页面，保留原始分页符、公式和图表源码。

支持本地上传、粘贴图片、内嵌 Base64、网络图片，以及引用式图片和 HTML `<img>`。重复引用同一张图片时只保存一份，代码示例中的图片语法不会触发下载。网络图片会先直接下载，失败后尝试图片代理；无法获取的图片保留原始引用，并在压缩包的 `export-notes.txt` 中列明。导出使用点击时的内容，保留编辑器中的原文。

12. **PNG 导出**：在「导出」菜单选择「PNG」生成高清图片
13. **PDF 导出**：在「导出」菜单选择「PDF」后直接下载，正文文字可选择和编辑
14. **HTML 导出**：在「导出」菜单选择「HTML」生成HTML页面
15. **预览缩放**：使用 +/- 按钮调整预览大小（50%-150%）

## 技术栈

### 核心框架
- **前端框架**：原生 HTML/CSS/JavaScript
- **Markdown 解析**：marked.js
- **图片生成**：html2canvas
- **PDF 生成**：jsPDF 矢量文本层（直接下载并保留可编辑文字）

### 数学与图表
- **数学公式渲染**：KaTeX + mhchem（化学公式扩展）
- **流程图渲染**：Mermaid.js
- **数据可视化**：Apache ECharts

### UI与交互
- **图标字体**：Font Awesome
- **样式设计**：现代化 CSS Grid/Flexbox/变量
- **响应式设计**：移动端适配
- **PWA支持**：manifest.json 安装元数据

## 技术实现与核心逻辑亮点

### 渲染优化
- **独立导出DOM**：导出时创建隔离节点避免影响预览，确保样式一致性
- **异步渲染管线**：数学公式→图表→ECharts 串行渲染，确保导出完整性
- **ID冲突解决**：为导出节点的Mermaid图表生成唯一ID，避免预览区干扰
- **代码块换行**：移除水平滚动，使用CSS自动换行确保长代码完整显示

### 公式与图表
- **KaTeX集成**：支持mhchem化学扩展，正确处理上标语法 `^{2}` 
- **Mermaid渲染**：异步图表生成，支持主题配置和错误处理
- **ECharts可视化**：动态数据图表，响应式尺寸适配
- **模板系统**：内置数学、物理、化学公式和图表模板

### 储与导出
- **Base64管理**：Markdown中短码展示，导出时替换完整数据
- **多格式支持**：PNG 位图与可编辑文字 PDF 双格式导出
- **样式变量化**：CSS变量统一管理，实时预览无重排
- **错误降级**：html2canvas多尺度重试，确保导出成功率

### 用户体验
- **智能预处理**：自动识别公式语法，预处理特殊字符
- **键盘快捷键**：提升编辑效率，支持常用操作
- **响应式设计**：适配多种屏幕尺寸和导出比例
- **通知反馈**：操作状态实时提示，错误信息友好展示


## 本地部署

1. 克隆项目到本地
2. 使用任意HTTP服务器启动

开发验证使用 Node.js 22 或更新版本，运行 `npm ci` 后执行 `npm test`。测试使用与页面一致的 Marked、KaTeX 版本验证公式解析。

### 构建与 Vercel 部署

运行 `npm run build` 生成 `dist/`，然后使用 HTTP 服务器提供该目录，例如 `python3 -m http.server 8080 --directory dist`。构建会把当前 Git commit 的前 7 位写入右上角版本按钮，点击打开 `huyiwen/xiaolin-madopic` 中对应提交，悬停可查看完整哈希。直接提供未构建的源码目录时，该位置显示「本地开发」。

仓库中的 `vercel.json` 已指定构建命令 `npm run build` 和输出目录 `dist`。在 Vercel 导入此仓库并连接生产分支后，每次 push 会自动构建和部署。构建优先使用 Vercel 提供的 `VERCEL_GIT_COMMIT_SHA`，本地构建则读取 Git HEAD，因此版本按钮始终对应本次构建的代码，回滚部署也会显示对应的旧版本。仓库当前使用 SHA-1，按钮显示的是 Git commit 的短哈希。
